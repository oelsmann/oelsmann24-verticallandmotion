# Input data and projection diagnostics

This versioned folder contains **two executed notebooks** and their supporting
Python source. Embedded plots make the notebooks viewable on GitHub without
downloading the inputs. Scientific calculations import the corrected production
package under `src/oelsmann24_verticallandmotion/`; there is no copied model here.

1. [Input/source data](01_input_data.ipynb): file/variable/dimension/unit inventory;
   reconstruction trends, uncertainty and spatial-footprint contours; GNSS trends
   and errors; GIA fields; coastal mask and observation weights.
2. [Corrected projection comparison](02_projection_comparison.ipynb): mean ± ensemble
   standard deviation at **Venice, Skellefteå, London, Tokyo, Brisbane and New York**;
   full global maps of mean/std for both `converge-to-gia` and `constant`; and
   differences between modes. Only corrected-model results are shown.

The plots show the VLM/GIA contribution to relative sea level, **not total
climate-driven sea-level projections**. Positive values indicate rising water
relative to land. City coordinates are listed explicitly in the notebook and are
representative city locations rather than exact paper tide-gauge locations.

## Reproduce from a fresh clone

From the repository root:

```sh
uv sync --locked --group diagnostics --dev
uv run --locked --group diagnostics python diagnostics/execute_notebooks.py
```

Optional small grid-coverage tests (no public data required):

```sh
uv run --locked --group diagnostics pytest diagnostics/test_helpers.py
```

To refresh only the projection notebook, add
`--notebook 02_projection_comparison.ipynb` to the execution command.

Obtain the five inputs from the [public archive](https://doi.org/10.5281/zenodo.18199757)
and place them under `data/inputs/reference/`, or set the `VLM_INPUT_DIR` environment
variable to the directory containing them. The notebooks do not download this large
archive automatically. Cartopy may fetch the small Natural Earth 110m coastline
dataset on its first plot and reuse its local cache thereafter.

You can also open the notebooks interactively and choose the project's
`.venv/bin/python` interpreter. Each notebook's configuration cell exposes input/output
directories. The projection notebook also exposes years, sample count, seed, and
the map year. The executed defaults are 500 samples, seed 1234, base year 2000,
ten-year steps through 2300, and map year 2150.

To run the same model/cache pipeline without Jupyter:

```sh
uv run --locked --group diagnostics python diagnostics/helpers.py
```

The helper accepts `--input-dir`, `--output-dir`, and `--force`. Notebook inputs and
outputs can also be located with `VLM_INPUT_DIR` and `VLM_DIAGNOSTICS_DIR`.

## What is tracked

This folder tracks notebook source with moderate-sized rendered outputs, shared
plotting/run helpers, and this guide. It does not track raw inputs, NetCDF datasets,
source snapshots, local environments, standalone PNGs or private paths.

Generated projection products default to ignored
`data/diagnostics/shared_notebooks/global_grid/`. The previous coastal-only run is
preserved in the parent directory, alongside the input notebook's figures/inventory:

- `converge-to-gia_mean_std.nc`, `constant_mean_std.nc`: actual finite-ensemble
  mean and population standard deviation (`ddof=0`) at every saved decade;
- `*_samples.nc`: full samples generated by the production package;
- `locations.lst`: six cities plus all 64,800 global 1° cell centers, including
  ocean and land (89.5°S–89.5°N, 179.5°W–179.5°E); map cells reach the poles/date line;
- `manifest.json`: input/source hashes, software versions, run settings and city
  coordinates; the cache refreshes when these change;
- `figures/`: standalone figures reproduced from the notebook cells.

The two modes use identical input data, locations, years, seed and sample count.
Both retain the spatial observation/GIA blend. Convergence integrates the 2050–2150
rate taper; constant mode continues the secular rates and trend error. The separate
GRW displacement-envelope treatment is unchanged. Neither mode supplies a complete
spatial error covariance model. Color limits are shared between modes and clipped
only for plotting; map sites are not an area-weighted global statistic.
No coastal or land/ocean mask is applied to the displayed projection field. The
production model still limits observation influence by its existing coastal and
distance weights; wherever that weight is zero, including the open ocean, the
result is GIA RSL and its uncertainty. Inland RSL values are a model field, not
projections of inland inundation. Both modes are identical at GIA-only locations.
Their open-ocean difference is therefore zero, not missing data.

The `diagnostics` dependency group is optional and is not installed by the production
Docker image. Existing local-only exploratory notebooks remain under ignored
`data/discovery/` and are separate from these curated, versioned notebooks.
